# V333 — naprawa panoramy pierwszej sceny

Usunięto dodatkowe przesuwanie górnych dziesięciu wierszy panoramy areny.
Przesunięcie obejmowało całą klatkę, więc odklejało górę głowy idącej z boku
dziewczyny. Panoramiczne klatki ponownie zachowują spójne położenie postaci.

Build stereo: `build/visual-prototype-v333.xex` i JSON obok. Zbudowano 298
współdzielonych wierszy i 2560 B kodu. Nie uruchamiano testów, emulatora ani
Atari; ostatnim potwierdzonym sprzętowo wydaniem pozostaje v330.
