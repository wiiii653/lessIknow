# V336 — stała jasność klatek ciosu Trevora

Klatki zamachu i ciosu używają teraz tej samej wartości jasności `COLPF1=$66`.
Wcześniejsza tabela przełączała między `$66` i `$68`, rozjaśniając klatki
zamachu względem ciosu. Paleta spokojnego wejścia Trevora pozostaje bez zmian.

Build stereo: `build/visual-prototype-v336.xex`; SHA-256:
`5b8acd50be3d3a275aa3a94ce58f2d320d614f785f508598fcc39d2c168f9cb3`.

wydaniem potwierdzonym sprzętowo.
