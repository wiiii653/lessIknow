# V331 — cloud motion and a larger heart

The original attempt at additional cloud parallax in the arena panorama shifted the whole
upper rows, including the head of the walking girl. That parallax was removed
in v333; the panorama was restored to the v175 frames. Details: [v333](V333_PANORAMA_FIX.md).

In the kiss scene the full heart remains visible one phase longer. In that
phase it uses quadruple PMG width and has the same recognisable shape as the
previous phase; then it breaks apart into particles. The heart palette has stronger,
saturated colours. No changes to ticks or the timeline.

Stereo build: `build/visual-prototype-v331.xex` and the JSON beside it. It has 298
shared rows and 2560 B of code. SHA-256: `ec53357d4c3ec32a5d67375f339fe953406f193e28463adbaf80d2c2920c6c76`.

`0964700654e76123e2a5d1102d61a686ec7b1e36918fc62814e4ab02c9030941`).
No tests or emulator were run. This build does not yet have confirmation
of working on a physical Atari; the last hardware-confirmed one remains v330.
