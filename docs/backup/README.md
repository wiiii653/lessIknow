# Documentation Backup

The archived Markdown files record earlier versions of the demo, technical
audits and proposals. For current build instructions, validation and graphics
polish, start with the [documentation guide](../README.md).

- The `Vxxx_*.md` files record changes and experiments by demo version.
- The [original timeline](TLIKTB_Atari_Timeline_v2.md) and
  [technical constraints draft](TLIKTB_Technical_Constraints.md) record
  the early production plan.
- The [opening brief](TERMINAL_OPENING_BRIEF.md),
  [terminal text plan](TERMINAL_TEXT_PLAN.md), and
  [outro review](OUTRO_TEXT_REVIEW.md) preserve earlier copy and design decisions.
- The [v035 music-bank audit](MUSIC_BANK_AUDIT.md) records measured decoder use.
- The [AVG startup report](REPORT_FOR_CODEX_AVG_RAMBO_START.md) and
  [loader flicker handoff](LOADER_FLICKER_HANDOFF.md) document earlier
  hardware investigations.
