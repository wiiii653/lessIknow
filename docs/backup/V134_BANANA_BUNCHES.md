# V134 — legible banana bunches

[READ] The previous motif consisted of three converging arcs.
It was replaced by hand-drawn silhouettes of three fruits: separate tips,
black seams, a shared thick stem and golden shadows on the yellow peel.
The tile was enlarged from 48 to 64 units. Rotation and scale still use the
same 32 phases; scene boundaries and the music clock remain unchanged.

[READ] The frame set is shared by the earlier rotozoomer and act 5.
The tunnel still uses the previous frames and palettes. The bank count did
not increase; the renderer occupies 996 B in the existing 1024 B slot.

[READ] Preview of the 6502 callback execution in four phases:
`build/v134-banany-preview.png`. The preview colours are a PAL approximation.
Release: `build/visual-prototype-v134.xex`.

[READ] `make check`: 86 tests, 83 passed and 3 skipped because the archival
v126 is missing. Atari800 PAL/1088XE: 15 346 872 identical stereo POKEY bytes
against v035, the whole track. This is not a listening test on physical Atari.
