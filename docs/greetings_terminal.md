# Greetings terminal

Source [outro_text.py](../tools/outro_text.py).

The terminal keeps three lines of history above the active prompt. Each greeting
types on the bottom row and the cursor keeps blinking during the reading pause.
When the next line starts, the window scrolls by one row.
The final four lines stay in place and fade to black with the boy's portrait.

## Starting history

The scrolling [credits terminal](outro_text.md) flows into the first greeting
at the same cadence, with the last three credit lines still visible.
